# Optional song-select reader

Quick Checker's automatic osu!stable song-select detection can install:

- OsuMemoryDataProvider 0.10.3 — Piotrekol — GPL-3.0-or-later
- ProcessMemoryDataFinder 0.8.5

The DLLs are not included in this source archive. `setup_native.ps1` downloads them from their NuGet packages when the user explicitly runs setup.
